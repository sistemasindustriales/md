Sistema de Seguimiento de Colectivos

Versión HTTPS para habilitar funciones de geolocalización

¿Por qué esta solución?

Los navegadores modernos solo permiten el uso de geolocalización en contextos seguros (HTTPS). Esta página actúa como contenedor seguro para tu aplicación, permitiendo el uso completo de todas las funciones de ubicación.

1 Contenedor seguro

Esta página está servida mediante HTTPS, lo que permite utilizar la API de geolocalización.

2 Iframe con tu aplicación

Tu aplicación HTTP original se carga dentro de un iframe, manteniendo todas sus funcionalidades.

3 Comunicación segura

El iframe puede comunicarse con esta página para habilitar las funciones de ubicación.
